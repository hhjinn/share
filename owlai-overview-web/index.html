자주 묻는 질문

어떤 DB를 연결할 수 있나요?

TmaxTibero의 Tibero, OpenSQL, OwlDB와 Oracle, PostgreSQL, MySQL, MariaDB, AWS RDS, Supabase를 연결할 수 있습니다. 질문에는 조회만 실행해 데이터를 바꾸지 않습니다.

DB를 연결하지 않아도 쓸 수 있나요?

네. 웹 검색과 올린 파일로 답합니다. DB를 연결하면 사내 데이터로도 답합니다.

회사 데이터는 어떻게 보호하나요?

조직마다 데이터가 따로 분리되고, 역할마다 쓸 수 있는 DB와 문서를 정합니다. DB에는 조회만 실행하고 전송은 TLS로 암호화합니다. AI가 실행한 SQL과 읽은 문서는 관리자가 보는 활동 기록에 남습니다.

회사 데이터가 외부로 나가나요?

클라우드에서는 질문과 답에 쓰인 문서 발췌, DB 조회 결과가 외부 AI 공급자(OpenAI, 미국)를 거쳐 처리됩니다. 서비스 데이터는 AWS 서울 리전에 저장됩니다. 업무 데이터를 사외로 보낼 수 없다면 구축형에서 자체 모델을 쓰면 질문과 조회 결과가 회사 밖으로 나가지 않습니다.

회사 내부에 설치할 수도 있나요?

네. 구축형은 회사 서버에 OwlAI를 설치합니다. AI 모델은 자체 GPU 서버의 오픈 모델이나 회사가 승인한 외부 API 중에서 고릅니다. 인터넷이 막힌 폐쇄망에서도 업데이트 파일을 올려 씁니다.

도입에 얼마나 걸리나요?

클라우드는 가입하면 바로 씁니다. 구축형은 클라우드로 업무 적합성을 확인하고(2~4주), 회사 서버에서 시험한 뒤(4~8주) 정식 도입(2~3개월)하는 순서를 권합니다. 기간은 예시이며 규모에 따라 달라집니다.
