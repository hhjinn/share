## OwlDB 예상 비용 계산기 사용 안내

- 왼쪽 입력 영역에서 CSP, DB 유형, 라이선스 유형, 구성 방식, 에디션, 인스턴스, DR 구성, 스토리지를 선택하면 오른쪽에 결과가 즉시 계산됩니다.
- 결과의 "비용 구성 상세 내역"과 "계산 근거"를 펼치면 항목별 수량, 단가, 계산식과 적용 규칙을 확인할 수 있습니다.
- 가격과 규칙은 화면 우측 상단 "관리자 설정"에서 수정할 수 있습니다. 변경 내용은 사용 중인 브라우저에만 저장되며, 다른 사람과 공유하려면 관리자 설정의 JSON 내보내기로 파일을 전달하거나 이 저장소의 HTML 파일을 갱신해야 합니다.
- 표시 가격은 [OwlDB] 예상 비용 계산기 엑셀의 가격표를 기준으로 하며, 확정 가격이 아닙니다.

## 파일 갱신 방법

1. 저장소에서 Add file 을 눌러 Upload files 를 선택합니다.
2. 같은 이름의 HTML 파일을 올리고 Commit changes 를 누르면 기존 파일이 교체됩니다.
3. 1~2분 뒤 같은 링크에 반영됩니다. 이전 화면이 보이면 브라우저를 새로 고침하세요.
